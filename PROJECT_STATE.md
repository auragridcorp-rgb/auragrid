# AurAgrid project state

Last verified on the server: 2026-10-31. Read this, then `RESEARCH.md` (the
Phase 1 plan and source licensing) and `deploy/README.md`, before changing anything.

AurAgrid is a small L402 data oracle. It sells two feeds computed from its own
Bitcoin and Lightning nodes and gives away seven more: delayed or daily copies
of the paid two, and five from U.S. public-domain sources (EIA, NOAA, USGS).
Every response carries `provenance`. Nothing is simulated: a feed without real
data answers 503.

## Rules

1. **The system never moves funds.** No sweeps, no outgoing payments. The old
   `sweep_to_vault.py`, `dynamic_liquidity_sweep.py` and `auragrid_swarm.py` are
   deleted; cron only has `@reboot ~/start_auragrid_services.sh` (starts the DVM).
2. **Only real data with clear redistribution terms** (see `RESEARCH.md` §2).
   No mock, sample or fallback values anywhere.
3. Run Python from the `auragrid_env` conda env:
   `/home/ubuntu/miniconda/envs/auragrid_env/bin/python`.
4. Secrets are never committed: `gateway.secret`, `/etc/auragrid/env`
   (`EIA_API_KEY`), `~/.auragrid/admin_password`, `~/.aperture/aperture.yaml`.

## Services (systemd units in `deploy/systemd/`)

| Unit | Role | Listens |
|---|---|---|
| `auragrid-fetcher` | Pulls every upstream feed on its own schedule into `var/feeds.db` (SQLite snapshot store). Reads `EIA_API_KEY` from `/etc/auragrid/env`; read-only filesystem except `var/` | - |

| `lnd` | Mainnet LND; REST 127.0.0.1:8081; source for `ln-network`, issues L402 invoices | local |
| DVM | `dvm/nip90_worker.py` in tmux session `auragrid_dvm` (Nostr NIP-90) | - |

## Clients

- `client.py`: hardened L402 client (mandatory per-payment cap, session budget,
  quote check, preimage check, no redirects, signature verification hook).
- `auragrid_sdk/mcp_server.py`: FastMCP server, one tool per endpoint; paid
  tools pay through `client.py` only when `AURAGRID_MAX_SATS` and an LND wallet are set;
  verifies signatures when `AURAGRID_SIGNING_PUBKEY` is pinned.
- `auragrid_mcp/` (PyPI `auragrid-mcp`): ships a copy of `client.py`
  (`tests/test_client_copies.py` keeps them identical). PyPI has only 0.1.0, which
  contains no code (metadata only); 0.2.0 is built from this repo but not uploaded.
