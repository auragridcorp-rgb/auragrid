# AurAgrid Revenue Target Guideline & Dynamic Model

## Primary Financial Objective
- **Monthly Target:** $1,000 to $50,000+ USD equivalent in satoshis (scaling via hybrid retail/wholesale tiers).
- **Primary Use of Funds:** Expanding Oracle Cloud block storage, scaling the autonomous agent fleet, and covering node operational overhead.
- **Settlement Rail:** Lightning Network (L402) -> Local Node 2 -> Non-custodial Mt. Pelerin Bridge Wallet -> USD Fiat Liquidation.

---

## 18-Tier Hybrid Architecture Pricing Matrix
AurAgrid monetizes energy telemetry and market intelligence across a dual-tier L402 paywall suite:
- **Retail Tier (6 Endpoints):** Single-call micro-transactions ($0.50–$2.00 / 500–3,000 sats) for ad-hoc agent polling.
- **Wholesale Tier (12 Endpoints):** Batch matrix queries ($30.00–$80.00 / 50,000–120,000 sats) for quants and institutional ESG swarms.
